# odin-recipes
This is The Odin Project's Recipes HTML project.

In this project I demonstrated my knowledge of HTML. I created a simple website for recipes. The website consists of a homepage
and several webpages for individual recipes. Each web page shows my knowledge of how to use various HTML elements. For instance, 
I demonstrate how to use a relative link within an anchor element, I demonstrate how to add images using the img element with the 
src and alt attributes, additionally I show how to use heading and list elements.

Although this project was more of a demonstration of HTML knowledge, I learned quite a bit as well as I progressed through it.
For instance, I was able to practice writing concise and descriptive commit messages. In past projects, I struggled with writing good 
commit messages, however, after reading through cbeams "How to Write a Git Commit Message" article, I was able to see how my commit messages
in this project read more naturally. Additionally, as stated in the curriculum, HTML documents are where we place the content of our webpages
and they sort of represent the skeletal structure of our webpage. I was able to see this skeletal structure after completing my website and 
visualized how it could be transformed visually however I wanted.
